# Prism

Prism je lokální webová aplikace pro pohodlné procházení dokumentace v Azure DevOps pull requestech. Spustíš ji přes Docker a zadáš URL pull requestu.

Markdown, HTML a Mermaid diagramy zobrazí v čitelné podobě. Můžeš porovnávat změny, procházet strom složek, označovat zkontrolované soubory a přidávat komentáře s citacemi.

Review lze publikovat do DevOps nebo připravit ke sdílení v Teams. Aplikace si pamatuje nedávné PR, upozorňuje na nové změny a při obnovení zachovává poznámky. Nabízí také různé skiny, fullscreen, klávesové zkratky a propojení s AI nástroji přes MCP.
